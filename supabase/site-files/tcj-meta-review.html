Method

Each anonymous dossier is reviewed independently by ChatGPT and Grok under the same frozen review contract. The first reviewer never sees the second reviewer’s output. Transport failures retry only within a bounded limit. One predefined schema-only repair is permitted; a second contract failure blocks the protocol rather than resampling until favorable.

A lost browser response is reconciled against the authoritative frozen server state before any further reviewer call. A completed review is never resubmitted merely because the mobile connection timed out.

Only after all six valid reviews are frozen may the server transition to meta review frozen. Candidate identities remain sealed until that gate passes.
