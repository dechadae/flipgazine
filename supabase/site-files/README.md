# Supabase `site_files` mirrors

This directory mirrors selected methodologically significant live assets stored in `public.site_files`.

It is **not** a second deployment mechanism. The live Supabase `public.site_files` rows remain the runtime source used by Flipgazine. These repository copies exist so GitHub and live Supabase can be compared and reconstructed during TCJ methodology work.

Current TCJ mirrors:

- `tcj-admission-review.html`
- `fg-page-tcj-admission-review-v2.js`
- `tcj-stage-b.html`
- `fg-page-tcj-stage-b-v1.js`

For TCJ, a frontend change that affects what the human can see or how methodological actions are initiated is versioned evidence-system infrastructure and should be mirrored here after the live write is verified.
